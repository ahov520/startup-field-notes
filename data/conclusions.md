## 核心结论（10 条可证伪判断）

每条判断都附 **2–4 个档案内案例**作证据。标「规律倾向」= 跨库反复出现；标「个案」= 勿外推成法则。

### 1. 【规律倾向】问卷/陈述偏好 ≠ 付费闭环；未验证付费前扩团队是加速死亡
- **抱抱窝**：问卷「看起来有需求」，付费弱；45 万自有资金耗尽关停。  
- **Lemon（新加坡）**：stated preference「人孤独」≠ revealed preference；约 9 个月关停。  
- **华语 AI 社交小程序（匿名全栈）**：生产力做得出 ≠ 生意；主动暂停。  
- **Centeni（巴西）**：兴趣≠紧迫；返还投资者约一半资本。

### 2. 【规律倾向】融资叙事可领先现金数月；「融资顺利」内部信之后常是停工
- **毫末智行**：十亿美元级叙事 + 2025 开年仍写融资顺利，数月后全员停工放假。  
- **景恩 AI 剪辑**：单一天使断供，三天内关公司；累计投入约 320 万+。  
- **Snaphunt（新加坡）**：投资人承诺 ≠ 账上现金；融资延迟后清算。  
- **极越**：股东输血中断 → 闪崩/预重整；员工·供应商·车主三角爆雷。

### 3. 【规律倾向】CAC 有「地板」时，运营打平也救不了——尤其关系租自 Meta/平台
- **Klydo（印度）**：CM2 打平、履约尚可，CAC ₹900–1200 地板不动；主动关停。  
- **Qtrove**：LTV 撑不住 CAC；「Etsy 模型」不旅行。  
- **Dashdot（澳）**：Meta 广告冲击下 CAC 约翻倍，盈利公司一周级清算速度倒下。  
- **探鹿兼职 / 校联帮**：下载返现·地推大使获客贵，C 端流量≠B 端容积。

### 4. 【规律倾向】适航/四证/FAA 首批授权 ≠ 客户与现金流；低空/整机青年勿硬刚
- **亿航 EH216**：「四证齐全」后交付断崖、撤回营收指引；金句同构「能飞≠赚钱」。  
- **Guardian Agriculture**：FAA 授权 + TIME 发明奖 → **1** 付费客户；约 $51.7M 仍不够。  
- **Lilium / Volocopter**：欧系 eVTOL 破产；国家担保政治是二阶风险。  
- **雷柏/零度**：上市公司干净切断无人机业务（对照影翎持续失血）。

### 5. 【规律倾向】硬件众筹热 / 预购 ≠ 量产工装与售后；死后路径要立项日写好
- **森合 Oasa R1**：KS 约 $230 万众筹，早会解散；公开信认责，售后失联风险高。  
- **K-Scale Labs**：退还订金 + 开源全部 IP；对照宇树成本曲线。  
- **Embodied/Moxie**：云关停即变砖；OpenMoxie 是损害控制非商业模式。  
- **影石影翎**：主业现金牛 ≠ 第二曲线可无限输血（H1 影翎系巨亏叙事）。

### 6. 【规律倾向】政策 β / 补贴 / 安审可一夜间改写故事——勿把补贴当确定收入
- **考虫 / 优胜 / 家校产品**：考试生态·疫情·收费模式错位摧毁教培叙事。  
- **Manus**：Meta 收购被发改委安审禁止并责令撤销 → 独立运营「合规再创业」。  
- **杭州补贴中介判决**：按补贴额抽 20% 条款判无效；蹭补灰色链仍收割学生。  
- **众创尸检 / OPC 注册即补贴**：KPI 从面积切到真实性即清算日；园区约九成无成熟模式（旁证）。

### 7. 【规律倾向】竞赛金奖 / 媒体光环挡不住治理与单位经济；落地率远低于获奖叙事
- **后会友期**：挑战杯一等奖 → 众筹餐厅治理崩、警方介入。  
- **大创赛落地率 ~8.5%（赛后三年）**：与后会友期互相印证（媒体/报告转述口径）。  
- **北邮小西天**：16 队一年存活仅 **4**。  
- **神奇百货 / 泡否**：人设与话题融资不可持续。

### 8. 【规律倾向】AI 潮有三种典型死法：同质化免费碾压、范式迁移、平台/模型厂降维
- **妙鸭相机**：暑期爆款 → 同质化后团队解散；内部孵化≠独立造血。  
- **Yupp**：募 $33M + 130 万用户，**钱没花完**因 agentic 范式杀死 chatbot 评测层。  
- **Stormy / viktor.com**：Meta 禁止令 / Anthropic 进楔子 → 平台与模型厂是生存风险。  
- **景恩**：热潮里「有人愿投」≠ 可持续（与单一 LP 叠加）。

### 9. 【成功对照·可学结构】从熟悉场景打穿 + 不可规模化早期动作 + 明确筛赛道标准
- **饿了么**：宿舍痛点 → 高校渗透 → 白领；合伙规则前置；融资以到账为准。  
- **Stripe / Airbnb**：Collison installation；上门拍照转化翻倍——*Do Things that Don’t Scale*。  
- **影石**：痛点·头部毛利·百亿级规模三标准；出海放大供应链。  
- **Supabase**：定位 fit（开源 Firebase 替代）+ 先 PMF 再扩张；像只剩 $100K 一样运营。  
- **普渡 / 宇树**：场景任务优先于人形秀；垂直整合扛过濒死现金。

### 10. 【规律倾向】体面退出是能力：偿付、退款、注销路径、主动砍盈利线，都比硬撑体面
- **Ula / Ringan**：账上有钱也关 / 监管下偿付交还。  
- **拉勾·许单单**：主动申请破产重整；直播 60% 管理 / 40% 行业归因。  
- **Yupp / Centeni / Tract**：返还剩余资本或长篇 postmortem。  
- **Warikoo**：主动杀死仍盈利的课程线切订阅——退出伦理含「主动重构」。  
- **政府注销指引 2025**：校园关停合规工具已入库。

## 大学生创业行动清单

### 立项前
1. 写清 **方向筛选标准**（可抄影石三标准或抱抱窝「先写标准再调研」）。  
2. 做 **付费/预付实验**，禁止只用问卷自证（对照 Lemon/抱抱窝）。  
3. **Premortem**：政策 β、平台依赖、CAC 地板、合规牌照、EOL/退款路径各写一行。  
4. 读本地补贴细则；**补贴不进确定收入表**（杭州判决、OPC 园区）。  
5. 合伙人：股权、All-in、法人变更、双签财务（拉勾、Foccuz）。

### MVP
1. 从 **最熟场景** 打穿（饿了么范式），而不是 BP 上的全国想象。  
2. 做不可规模化的早期动作（Stripe/Airbnb），再谈增长公式。  
3. AI 项目默认：**demo≠生产级**（Seede/程梦琪）；算清 token/调用单位经济。  
4. 校园项目：6 个月内人事动荡高危（北邮）；别做「双端桥梁」却补不上商家端。  
5. 硬件/低空：优先外围与轻资产；众筹前写死交付与退款（森合/K-Scale）。

### 融资观
1. **到账才算结束**（饿了么）；承诺函当零。  
2. 勿单一 LP（景恩）；勿在没钱时才融资。  
3. 拒绝错配资金是能力（Cartwheel「No money is better than the wrong money」）。  
4. 融资顺利时反而要小步验证（家校复盘、芥末堆）。  
5. 深度科技注意资本地理（BioCompute 迁美叙事）与双时钟（Kintsugi FDA vs VC）。

### 退出伦理
1. 预设止损点与时间表（Will Hackett、4 SaaS 损切り、ETLR「无人挽留」）。  
2. 关停信四件套：时间表、退款/偿付、数据导出、对员工责任（InstantDB、Yupp、森合对照）。  
3. 主动破产/注销路径合法可用（拉勾、注销指引 2025）；拖欠不是韧性。  
4. 竞赛奖杯可进简历，**不可进公司治理真空**（后会友期）。  
5. 盈利线也可主动杀死以换主线（Warikoo）——退出含战略重构。

## 方法局限

1. **媒体偏差**：成功有公关、失败有流量；「闪崩」「独角兽」标题党需交叉验证。  
2. **幸存者偏差**：影石/饿了么/Stripe 被反复讲述；同阶段死去的匿名团队不可见。  
3. **金额未审计**：融资额、估值、亏损、CAC、落地率（含 ~8.5%）多为媒体/报告口径。  
4. **一手厚度不均**：欧美 farewell 与知乎长文较厚；国内青年整机/eVTOL 关停信仍缺。  
5. **非随机样本**：本仓库是通宵定向补缺口的便利样本，**不能**推断「创业成功率」。  
6. **时间切片**：截至 2026-09-09；进行中公司（nuwa、MiniMax 等）状态可能已变。  
7. **跨文化外推风险**：Qtrove「模型不旅行」、Centeni「美国标杆不移植」——成功模板有地理物理。
